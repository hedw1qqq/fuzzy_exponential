# Экспоненциальные нечёткие величины — PyQt6

[Скачать программу для Windows x64 в разделе Releases](https://github.com/hedw1qqq/fuzzy_exponential/releases/tag/v1.0.0)

Скачайте и запустите `FuzzyExponential-Windows-x64.exe`. Устанавливать Python не нужно.

Практическая работа по дисциплине «Неклассические логики» (МАИ, 2026). Программа выполняет арифметические операции над интервалами, фильтрует их по экспоненциальной функции принадлежности и группирует методом k-medoids.

## Запуск из исходного кода на Windows

1. Распакуйте архив в обычную папку (например `C:\Users\...\Documents\fuzzy-lab`).
2. Установите [Python](https://www.python.org/downloads/) версии 3.10 или новее. При установке можно отметить «Add Python to PATH».
3. Запустите **`install.bat`** для установки PyQt6, NumPy и Matplotlib (при первом запуске нужен интернет).
4. Запустите **`start.bat`** — появится окно PyQt6.

Альтернативно из PowerShell, находясь в папке проекта:

```powershell
py -m pip install -r requirements.txt
py app.py
```

Если команда `py` недоступна, используйте `python` вместо `py`.

Linux/macOS: `python3 -m pip install -r requirements.txt && python3 app.py` (на Linux должны быть доступны системные библиотеки для Qt).

## Работа в программе

1. В панели над графиками задайте скорость спада λ и порог отбора α. По умолчанию λ = 1 и α = 0,8000. Значение α от 0 до 1 можно ввести числом или выбрать ползунком.
2. На вкладке «Интервалы» введите границы двух интервалов. Доступны сложение, вычитание, умножение, деление и сравнение. Справа показаны интервалы и значения функции принадлежности в их центрах.
3. На вкладке «Кластеризация» сгенерируйте от 100 до 300 интервалов. Задайте число кластеров, метрику и предел итераций. Запустите расчёт. На двух графиках показаны весь набор и интервалы, прошедшие фильтр.
4. CSV содержит границы, λ, α, принадлежность центра, признак отбора и номера кластеров в обоих разбиениях. Вкладка «Журнал» сохраняет действия и результаты в файл.

## Теоретическая модель

Для λ > 0 функция принадлежности равна μ(x) = exp(−λx) при x ≥ 0 и нулю при x < 0. Это плотность экспоненциального распределения, делённая на её максимум λ.

У каждой величины есть один интервал [L, R]. При фильтрации проверяется условие μ((L + R) / 2) ≥ α. Границы остаются теми же. Для сравнения раздельные интервалы упорядочиваются по расположению, при касании или пересечении выводится ≈.

Арифметика работает с границами интервалов. Сумма равна [L₁ + L₂, R₁ + R₂], разность — [L₁ − R₂, R₁ − L₂]. При умножении и делении берутся минимум и максимум четырёх произведений или частных. Деление допустимо, когда интервал делителя лежит целиком по одну сторону от нуля.

### Генерация и кластеризация

Центр случайного интервала берётся из экспоненциального распределения с ограничением max(1, 3m), где m = ln(2)/λ — медиана. Полуширина равна max(0,05, m × U), где U равномерна на [0,03; 0,18]. Левая граница ограничена нулём.

Метод k-medoids начинает с одного случайного медоида, затем добавляет точки, наиболее удалённые от ближайшего уже выбранного медоида. На каждой итерации точки назначаются ближайшим медоидам. В каждой группе медоид заменяется элементом с минимальной суммой расстояний до остальных. Для отфильтрованного набора число кластеров ограничено его размером.

Доступны четыре меры расстояния. При w = R − L это расстояние Хаусдорфа max(|L₁ − L₂|, |R₁ − R₂|), |w₁ − w₂|, |w₁² − w₂²| и евклидово расстояние между парами границ.

Интервальная модель, фильтрация и алгоритм взяты за основу из [примера с распределением Вейбулла](https://github.com/Ecodrin/WeibullDistributionDemonstrationProgram/tree/d82a4e76f5de63396ba5411ac01119c4768c8755/gui).

## Структура проекта

| Файл | Назначение |
|---|---|
| `app.py` | Запуск, навигация, вкладки журнала и справки |
| `ui/values.py` | Ввод параметров, арифметика и сравнение |
| `ui/clusters.py` | Генерация набора, таблица и кластеризация в `QThread` |
| `ui/widgets.py` | Общие виджеты и графики Matplotlib |
| `ui/style.qss` | Оформление Qt |
| `ui/storage.py` | Файловый журнал и экспорт CSV |
| `fuzzy_numbers.py` | Независимая модель нечётких величин, операции и сравнение |
| `clustering.py` | Независимые генерация, расстояния и кластеризация |
| `tests/test_logic.py` | Тесты математики |
| `tests/test_ui.py` | Smoke-проверки основных действий GUI (если установлен PyQt6) |
| `requirements.txt` | Зависимости Python |
| `install.bat`, `start.bat` | Установка и запуск на Windows |

Импорт библиотек **без** GUI:

```python
from fuzzy_numbers import FuzzyNumber, calculate
from clustering import generate_samples, k_medoids, pairwise_distances

print(calculate(FuzzyNumber(2, 3), FuzzyNumber(5, 6), '+'))
samples = generate_samples(150, lam=1)
labels, medoids = k_medoids(pairwise_distances(samples), k=3)
```

## Сборка EXE

Для сборки `v1.0.0` использован Python 3.12.1 x64. Выполните в PowerShell из корня проекта:

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements-build-windows.txt
$qss = (Resolve-Path -LiteralPath ui/style.qss).Path
$previousPath = $env:Path
try {
    $env:Path = "$env:windir\System32;$env:windir"
    & .\.venv\Scripts\python.exe -m PyInstaller --clean --onefile --windowed --noupx `
      --name FuzzyExponential-Windows-x64 --add-data "${qss}:ui" app.py
} finally {
    $env:Path = $previousPath
}
```

Готовый файл находится в папке `dist`.
