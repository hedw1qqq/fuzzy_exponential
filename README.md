# Экспоненциальные нечёткие величины — PyQt6

Практическая работа по дисциплине «Неклассические логики» (МАИ, 2026). Программа выполняет арифметические операции с нечёткими величинами и группирует сгенерированные величины по расстоянию между их α-срезами.

## Запуск на Windows 10/11

1. Распакуйте архив в обычную папку (например `C:\Users\...\Documents\fuzzy-lab`).
2. Установите [Python](https://www.python.org/downloads/) версии 3.10 или новее. При установке можно отметить «Add Python to PATH».
3. Запустите **`install.bat`** для установки PyQt6, NumPy и Matplotlib (при первом запуске нужен интернет).
4. Запустите **`start.bat`** — появится окно PyQt6.

Альтернативно из PowerShell, находясь в папке проекта:

```powershell
py -m pip install -r requirements.txt
py app.py
```

Если команда `py` недоступна, используйте `python` вместо `py`.

Linux/macOS: `python3 -m pip install -r requirements.txt && python3 app.py` (на Linux должны быть доступны системные библиотеки для Qt).

## Работа в программе

1. На вкладке «Величины и операции» введите `a` и `λ` для A и B. Нажмите «Построить A и B», чтобы обновить графики. Для расчёта выберите операцию и нажмите «Вычислить». Кнопка «Сравнить» показывает знак сравнения и числовые оценки величин. Ползунок α показывает срезы величин, изображённых на графике.

2. На вкладке «Кластеризация» задайте объём набора от 100 до 300 и нажмите «Сгенерировать набор». При одинаковых настройках и `seed` программа повторит выборку. Выберите число кластеров `k` или порог расстояния `d` и нажмите «Выполнить кластеризацию». Номера кластеров появятся в таблице. Кнопка «Экспорт таблицы CSV» сохраняет параметры величин и номера кластеров.

3. На вкладке «Журнал» можно просмотреть историю действий и сохранить её копию. Автоматический журнал содержит параметры введённых и сгенерированных величин, результаты операций и номера кластеров. По умолчанию файл находится в `logs/app.log`. Фактический путь указан под журналом.

4. На вкладке «О модели» собраны формулы и краткое описание расчётов.

## Теоретическая модель

Для сдвинутого экспоненциального распределения плотность:

\[
f(x) = \lambda e^{-\lambda(x-a)}, \quad x \geq a, \; \lambda>0.
\]

В задании функция случайной величины используется **как функция принадлежности**. Мы используем плотность, нормированную на максимум `λ`:

\[
\mu_A(x) = \begin{cases}0,&x<a,\\e^{-\lambda(x-a)},&x\geq a.\end{cases}
\]

**α-срез:** при `0 < α ≤ 1` имеем `Aα = [a, a − ln(α)/λ]`.

В коде хранится **199 уровней `α` от 0.01 до 1**. Это численное приближение: при `α→0` функция имеет неограниченный справа носитель. На графике исходных величин A и B используются точные функции; результаты арифметических операций рисуются путём приближённого восстановления по α-срезам.

Операции по принципу обобщения (интервальная арифметика для срезов):

- Сумма: `[a1+b1, a2+b2]`.
- Разность: `[a1−b2, a2−b1]`.
- Умножение: минимум и максимум четырёх произведений концов интервалов.
- Деление: обращение интервала делителя и умножение. Если срез при `α = 0.01` содержит ноль, деление на расчётной сетке невозможно. Срезы ниже этого уровня программа не рассматривает.
- Сравнение: скаляр `S(A) = (1/(αmax−αmin)) ∫(Lα+Rα)/2 dα`, вычисляемый по трапециям. Это учебный способ ранжирования, не универсальный порядок.

После операций нечёткая величина **не обязательно экспоненциальная**, поэтому результат сохраняется в общем виде по α-срезам.

### Генерация и кластеризация

Синтетические данные: `a` и `λ` генерируются из четырёх искусственных групп либо равномерно в заданных пределах. Метрика — RMS-отклонение границ α-срезов:

\[
d(A,B) = \sqrt{\frac{1}{2m}\sum_{i=1}^{m} [(L_{Ai}-L_{Bi})^2+(R_{Ai}-R_{Bi})^2]}.
\]

Применяется **агломеративная кластеризация с полной связью (complete linkage)**. Два способа остановки: ровно `k` кластеров или минимальное межкластерное расстояние выше порога `d`. Расстояние считается по нечётким величинам, а диаграмма `(a, 1/λ)` служит лишь для визуализации.

## Структура проекта

| Файл | Назначение |
|---|---|
| `app.py` | PyQt6 GUI, графики Matplotlib, потоки, журнал, CSV |
| `fuzzy_numbers.py` | Независимая модель нечётких величин, операции и сравнение |
| `clustering.py` | Независимые генерация, расстояния и кластеризация |
| `tests/test_logic.py` | Тесты математики |
| `tests/test_ui.py` | Smoke-проверки основных действий GUI (если установлен PyQt6) |
| `requirements.txt` | Зависимости Python |
| `install.bat`, `start.bat` | Установка и запуск на Windows |

Импорт библиотек **без** GUI:

```python
from fuzzy_numbers import exponential, calculate, compare
from clustering import generate_samples, cluster_numbers
A, B = exponential(2, 1), exponential(5, 1.5)
C = calculate(A, B, '+')
print(C.left[-1], C.right[-1])
samples = generate_samples(150)
print(cluster_numbers([s.number for s in samples], k=4))
```
