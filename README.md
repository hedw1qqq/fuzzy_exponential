# Экспоненциальные нечёткие величины — PyQt6

Практическая работа по «Неклассическим логикам». **Учебное соглашение преподавателя: одна нечёткая величина в вычислительной части представлена ровно одним α-срезом (отрезком).** Для сопоставимых операций и кластеризации используется один общий настраиваемый уровень α.

> В общей теории нечёткая величина определяется функцией принадлежности, а не единственным α-срезом. Поэтому ниже речь об **интервальном представлении на фиксированном α**. Это осознанное ограничение учебной модели, не новое определение нечёткой величины.

## Запуск

Для Windows 10/11 нужен Python 3.10+:

1. Запустить `install.bat` — установить PyQt6, NumPy и Matplotlib.
2. Запустить `start.bat`.

```powershell

py app.py
```

## Модель

Сдвинутая экспоненциальная плотность имеет вид

\[
f(x) = \lambda e^{-\lambda(x-a)}, \quad x\ge a, \lambda>0.
\]

После нормировки на её максимум λ получаем функцию принадлежности **исходной** величины:

\[
\mu_A(x)=\begin{cases}
0,& x<a,\\
e^{-\lambda(x-a)},& x\ge a.
\end{cases}
\]

При выбранном уровне \(\alpha\in(0,1]\) вычисляется **один интервал**:

\[
A_\alpha = [L_\alpha,R_\alpha] = \left[a,a-\frac{\ln\alpha}{\lambda}\right].
\]

В программе у каждого объекта `FuzzyNumber` ровно **один** уровень `alpha` и **одна пара** границ `left, right`. Ранее использовавшаяся сетка из 199 уровней больше не хранится.

Пример при \(a=2,\lambda=1,\alpha=0.5\): \(A_{0.5}=[2,2.693147\ldots]\).

### Операции

Операции выполняются **только на одном общем α**:

- Сумма: \([l_1+l_2,r_1+r_2]\).
- Разность: \([l_1-r_2,r_1-l_2]\).
- Произведение: минимум и максимум четырёх произведений концов.
- Деление: интервальное обращение делителя и умножение; запрещено при попадании нуля в делитель.
- Сравнение: по серединам интервалов \((l+r)/2\) с погрешностью; это **учебный критерий**, не полный порядок нечётких множеств.

Если уровни α различаются, операции и вычисление расстояния отклоняются с ошибкой.

**Важно:** после операций `C=A+B` и т. п. известен только интервал \(C_\alpha\). Функция принадлежности \(C(x)\) из одного интервала в общем случае не восстанавливается, поэтому в интерфейсе не рисуется выдуманная кривая для C. Исходные экспоненциальные кривые A и B рисуются по известным \(a,\lambda\).

### Генерация и кластеризация

Создаются 100–300 исходных экспоненциальных величин с параметрами \(a,\lambda\) — из четырёх искусственных групп или равномерно. Для каждой вычисляется ровно один α-срез с **общим для всей выборки** уровнем.

Для интервалов \(A=[L_A,R_A]\) и \(B=[L_B,R_B]\):

\[
d(A,B)=\sqrt{\frac{(L_A-L_B)^2+(R_A-R_B)^2}{2}}.
\]

Алгоритм: агломеративная кластеризация **complete linkage**. Останов по ровно `k` кластерам **либо** по максимально допустимому расстоянию `d`. При выборе `k` поле `d` неактивно, и наоборот. Значение `d=0.900` — начальное, его можно изменить после выбора режима порога.

График использует свойства интервала: **положение** \((L+R)/2\) и **размах** \(R-L\), а не параметры исходной экспоненты.

## Работа в интерфейсе

1. **Величины и операции**: задать \(a,\lambda\) для A и B и α (ползунок 0.01…1.00). После смены α интервалы и текущий результат **пересчитываются**. Кнопки — построить, вычислить, сравнить.
2. **Кластеризация**: задать количество 100–300, seed, способ генерации и **общий α**, нажать «Сгенерировать набор». Затем выбрать `k` или `d`, выполнить кластеризацию. Изменение α **сбрасывает ранее сгенерированный набор**, чтобы нельзя было случайно смешать уровни.
3. **Таблица**: α, левая/правая границы, положение, размах и кластер для каждого отрезка. **Экспорт CSV**: столбцы `id, a, lambda, alpha, left, right, width, cluster`. Журнал сохраняет α и границы каждого интервала.
4. **О модели**: краткая теория и ограничения.

## Модули

- `fuzzy_numbers.py` — независимая библиотека одного α-среза и арифметики.
- `clustering.py` — генерация, расстояние и complete linkage.
- `ui/values.py`, `ui/clusters.py` — экраны PyQt6.
- `ui/widgets.py`, `ui/style.qss` — графики, компоненты и оформление.
- `ui/storage.py` — журнал и CSV.
- `tests/test_logic.py`, `tests/test_ui.py` — математические и GUI-тесты.

Использование математической части независимо от UI:

```python
from fuzzy_numbers import exponential, calculate
from clustering import generate_samples, cluster_numbers

A = exponential(2, 1, alpha=0.5)
B = exponential(5, 1.5, alpha=0.5)
C = calculate(A, B, '+')
print(C.alpha, C.left[0], C.right[0])

samples = generate_samples(150, alpha=0.5)
labels = cluster_numbers([s.number for s in samples], k=4)
print(labels)
```

Тесты: `py -m unittest discover -s tests -v`. Для headless Linux можно использовать `QT_QPA_PLATFORM=offscreen`.
